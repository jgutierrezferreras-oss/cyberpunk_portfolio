# Cyberpunk Portfolio

Portafolio profesional con estilo Cyberpunk desarrollado como primer ejercicio de la asignatura Inteligencia Artificial.

El proyecto presenta un perfil profesional orientado al desarrollo de software y la Inteligencia Artificial, utilizando un diseño oscuro con elementos visuales en color rojo neón.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons

## Características

- Diseño Cyberpunk en modo oscuro.
- Diseño responsivo para computadoras, tablets y dispositivos móviles.
- Navbar flotante para navegar entre las diferentes secciones.
- Sección Hero con fotografía, presentación y biografía.
- Stack tecnológico presentado mediante tarjetas.
- Efecto neón al pasar el cursor sobre las tarjetas.
- Sección de proyectos de ejemplo.
- Filtros interactivos desarrollados con JavaScript.
- Footer con enlaces a redes sociales.
- Botón para volver al inicio de la página.
